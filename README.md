# mars
Универсальный JSON-RPC 2.0 интерфейс для взаимодействия с информационной базой 1С.

JSON-RPC 2.0 это легкий RPC-подобный протокол для взаимодействия систем ([Спецификация](https://www.jsonrpc.org/specification))

## Возможности

После внедрения в целевую конфигурацию информационной базы и публикации на http-сервере http-сервиса `JRPC2` появляется возможность делать к целевой информационной базе запросы по протоколу JSON-RPC 2.0

## Внедрение

1. Скачать и распаковать (или клонировать) проэкт В папке `cf`находится файл конфигурации `mars.cf`;
2. Объединить целевую конфигурацию (или новую пустую конфигурацию, если писпользуется в целях ознакомления) с конфигурацией `mars.cf`;
3. Опубликовать на http-сервере http-сервис `JRPC2`

## Использование

Послед внедрения на ендпоинт **{схема}://{адрес_сервера}:{порт}/{имя_информационной_базы}/hs/jrpc/invoke** можно делать POST-запросы JSON-RPC 2.0
