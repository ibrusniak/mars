# mars
[Українська](README.uk.md)

Универсальный JSON-RPC 2.0 интерфейс для взаимодействия с информационной базой 1С.

JSON-RPC 2.0 — это лёгкий протокол удалённого вызова методов ([спецификация](https://www.jsonrpc.org/specification)).

## Возможности

После внедрения в целевую конфигурацию информационной базы и публикации HTTP-сервиса `JRPC2` появляется возможность выполнять запросы к информационной базе по протоколу JSON-RPC 2.0.

## Внедрение

1. Скачать и распаковать (или клонировать) проект. В папке `cf` находится файл конфигурации `mars.cf`.
2. Объединить целевую конфигурацию с конфигурацией `mars.cf`. Если конфигурация используется только в ознакомительных целях, можно использовать новую пустую конфигурацию.
3. Опубликовать HTTP-сервис `JRPC2` на HTTP-сервере.

## Использование

После внедрения на endpoint:

```text
{схема}://{адрес_сервера}:{порт}/{имя_информационной_базы}/hs/jrpc/invoke
```

можно выполнять POST-запросы по протоколу JSON-RPC 2.0

Пример:
```text
POST /mars/hs/jrpc/invoke HTTP/1.1
Content-Type: application/json
```
```json
{
    "jsonrpc": "2.0",
    "method": "ping",
    "id": 1
}
```
Ответ:
```json
{
    "jsonrpc": "2.0",
    "result": "pong",
    "error": null,
    "id": 1
}
```

Приклад:
```text
POST /mars/hs/jrpc/invoke HTTP/1.1
Content-Type: application/json
```
```json
{
    "jsonrpc": "2.0",
    "method": "getProducts",
    "id": "2000"
}
```
