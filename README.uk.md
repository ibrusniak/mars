# mars

Універсальний JSON-RPC 2.0 інтерфейс для взаємодії з інформаційною базою 1С.

JSON-RPC 2.0 — це легкий протокол віддаленого виклику методів ([специфікація](https://www.jsonrpc.org/specification)).

## Можливості

Після впровадження в цільову конфігурацію інформаційної бази та публікації HTTP-сервісу `JRPC2` з'являється можливість виконувати запити до інформаційної бази за протоколом JSON-RPC 2.0.

## Впровадження

1. Завантажити та розпакувати (або клонувати) проєкт. У папці `cf` знаходиться файл конфігурації `mars.cf`.
2. Об'єднати цільову конфігурацію з конфігурацією `mars.cf`. Якщо конфігурація використовується лише з ознайомчою метою, можна використати нову порожню конфігурацію.
3. Опублікувати HTTP-сервіс `JRPC2` на HTTP-сервері.

## Використання

Після впровадження на endpoint:

```text
{схема}://{адреса_сервера}:{порт}/{ім_я_інформаційної_бази}/hs/jrpc/invoke
```

можна виконувати POST-запити за протоколом JSON-RPC 2.0.

Приклади:

Запит:
```text
POST /mars/hs/jrpc/invoke HTTP/1.1
Content-Type: application/json
```
```json
{
    "jsonrpc": "2.0",
    "method": "ping",
    "id": 1
}
```
Відповідь:
```json
{
    "jsonrpc": "2.0",
    "result": "pong",
    "error": null,
    "id": 1
}
```

Запит:
```text
POST /mars/hs/jrpc/invoke HTTP/1.1
Content-Type: application/json
```
```json
{
    "jsonrpc": "2.0",
    "method": "getProducts",
    "id": "2000"
}
```
